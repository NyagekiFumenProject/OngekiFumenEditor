中ProgramInfo 使用反射访问 Renderer/Timer；RangeValue OnError 吞异常。调试页可能随 Avalonia 内部变化失效；故障难以发现。优先寻找公开服务接口；OnError 至少记录日志或转发。
中拖放缓存 pressed event；DefaultDragDropManager 对非 pressed event 静默返回。拖放可能在特定输入设备、浏览器或取消路径失效，调用方误以为已开始。覆盖 mouse/touch/触控板/浏览器拖放，并明确失败返回/日志语义。
中MP3 解码从 Mp3FileReader 改为 AudioFileReader；NAudio 3 为 preview。格式识别、采样格式、seek、ID3、资源生命周期可能变化。加入真实 MP3/stream/损坏文件和多采样率回归。
低NU1507、Gekimini AdaptiveToolBar CS8632、若干既有 nullable/unused warning。当前不阻止构建，但会掩盖升级回归。设置 package source mapping；开启/统一 nullable；逐步清理 warning。
