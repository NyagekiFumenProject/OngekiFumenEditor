当没有内容溢出时，隐藏按钮		 第三方 Toolbar 模板始终显示右下角溢出按钮，只在无溢出时将其禁用，因此呈现灰色三角并永久预留 11px。已引入 AdaptiveToolBar，按 HasOverflowItems 同步按钮可见性，并在隐藏时回收预留空间。 ToolbarOverflowButton_IsHiddenUntilItemsOverflow 覆盖正常宽度、发生溢出以及重新展开三个状态，验证按钮可见性和边距回切。 升级 AvaloniaControlsToolBar 时核对 PART_OverflowButton 与 MainPanelBorder 模板部件名称，并保留三态布局回归，避免依赖模板变化后静默失效。
已修复
当展示的按钮被收入溢出时，再放出来就没有按钮icon也无法点击		 Toolbar 在主区域与溢出弹层之间搬移视图时会触发短暂 Unloaded；通用 ViewLocator 此时清空 DataContext，导致视图返回主区域后图标和命令绑定同时丢失。现在卸载仍执行生命周期清理，但保留定位器创建时的一对一 DataContext，并在加载时防御性恢复。 ViewLocator_ReattachedToolbarViewRestoresIconAndCommandBindings 验证视图卸载再挂载后 DataContext、图片源、命令、启用状态和实际执行结果均正常。 其他会跨视觉根移动内容的控件（Popup、Flyout、虚拟化面板）也应复用该生命周期回归；业务资源释放继续放在 OnViewBeforeUnload，不要依赖清空 DataContext。
已修复
物件属性窗口无法显示实时生成的控件		 问题包含两层：三个属性/操作 converter 曾直接返回输入对象，没有调用 Avalonia UI generator；接线后，页面末尾两个裸 ContentPresenter 的运行时 DataContext 仍为 null，使 SelectedObjects 绑定无法调用对象操作生成器。现已接通属性、单对象和多对象 generator，并把两个页面级操作宿主改为 ContentControl。 BrowserView_RendersGeneratedControls_AfterRefreshSelected 验证属性控件实际进入视觉树；BrowserView_RendersLaneNextOperationControl_AfterRefreshSelected 验证选择 LaneNextBase 后生成并绑定 ConnectableObjectOperationView。相关专项测试 9/9 通过，最终聚焦测试 1/1 通过，Desktop Debug 构建 0 错误；对象操作宿主修复签入 f016b0ec。 继续覆盖 Hold、Beam、Soflan 和多对象轨道操作面板，并增加真实 Desktop 选择/布局回归。双向写回、校验提示和撤销 action 继续由迁移审计 B-040 独立跟踪。
已修复
工具箱拖动物件到编辑器里面无法工作，物件并没有实际添加到编辑器上		 拖放源发送的是 ToolboxItemViewModel，编辑器只识别 ToolboxItem；同时没有处理 DragOver 来设置允许效果。已兼容两种 payload，补上 DragOver，统一清理拖放 token，并在创建对象为空时安全返回。 编辑器构建通过；拖放入口现在覆盖 DragEnter/DragOver/Drop，设计模式、锁定状态和无效对象均有明确分支。 增加真实指针拖放集成测试：验证 Move 效果、对象集合数量、坐标换算、一次撤销和 Drop 失败后的 token 清理。
已修复
部分DataGrid的宽度小于内容所需宽度，检查一下原因		 Avalonia DataGrid 的可调整列在空间不足时会压缩到默认最小值；迁移列没有设置内容级 MinWidth，且未开启横向滚动。已为六个受影响视图补充合理的列最小宽度和 HorizontalScrollBarVisibility="Auto"。 MigratedDataGrids_PreserveColumnMinimumWidthsAndHorizontalScrolling 覆盖六个视图，在 320px 宿主宽度下验证所有列不低于最小宽度。 新列同时审查 Width、MinWidth 和排序/重排行为；对窄窗口、长本地化文本和高 DPI 做快照或 headless 布局回归。
已修复
菜单点击时间计算器和当前选择物件查看器没出现对应界面，且对应菜单按钮变灰了		 两个命令处理器复制了元信息浏览器的接口解析，实际应解析各自的 ITGridCalculatorToolViewer 与 IFumenEditorSelectingObjectViewer，导致服务解析失败并使 CanExecute 变灰。已更正接口映射。 对应命令处理器已改为正确接口；全量 307 项核心测试通过，构建无错误。 为每个菜单命令建立“命令定义 - handler - tool interface”映射测试，并覆盖工具已打开时聚焦、未注册时禁用和切换文档后的 CanExecute。
已修复
编辑器Hold渲染出问题了，Hold长条被渲染成黑色而不是对应的颜色		 旧设置中的 System.Drawing.Color 被按对象形状反序列化为 Color.Empty（A/R/G/B 全为 0），渲染转换后自然变黑/透明。已加入兼容 JSON converter，按 ARGB 数字持久化，并在反序列化后对空颜色恢复默认 Hold 调色板。 EditorGlobalSettingJson_RoundTripsHoldColorsAsArgbNumbers、legacy object recovery 测试通过；完整核心测试 307/307。 为设置文件增加 schema/version 迁移；加入渲染像素或颜色转换回归，覆盖旧文件、透明色、自定义色和未知字段，避免设置格式再次漂移。

System.ArgumentException：命令要求 DisplayTimeSignatureItem，实际收到 FumenTimeSignatureListViewerViewModel		 BehaviorCollectionTemplate 在脱离行视觉树的位置创建行为，模板中的裸 {Binding} 继承了列表视图模型，而不是 DataGridRow.DataContext。已为 DoubleTappedCommandBehavior 增加按事件时读取关联控件 DataContext 的选项，并在时间签名、检查结果、子弹调色板列表及调色板选择对话框启用。 TimeSignatureRows_PassDisplayItemToDoubleTapCommand 验证真实 DataGridRow 传入正确项目并可执行强类型命令；DoubleTappedCommandBehavior_TracksAssociatedDataContextForRecycledRows 验证行复用后参数随新 DataContext 更新。 虚拟化或模板化行上的行为不要使用裸 {Binding} 作为强类型命令参数；优先使用关联控件的当前 DataContext 或显式类型代理，并保留行复用回归测试。
