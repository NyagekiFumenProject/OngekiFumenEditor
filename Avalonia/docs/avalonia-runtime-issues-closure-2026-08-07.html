已修复
Toolbar一些图标还是没有显示icon		 四个命令定义的 IconSource 为空，虽然对应 PNG 已嵌入资源。已补回 ResourceUtils.GetResourceUri(...)，保留现有 UriToBitmapConverter 加载链路。 ToolbarCommandDefinitions_ExposeExistingEmbeddedIcons 验证 URI 与资源流均可用；完整测试通过。 继续为新增命令执行“非空 URI + 资源可读”烟囱测试；资源文件改名时让 CI 立即失败，避免再次出现空白按钮。
已修复
物件属性窗口无法显示实时生成的控件		 三个属性/操作 converter 是占位实现，直接返回输入对象，没有调用 Avalonia UI generator。已分别接通单对象、多对象和属性 wrapper 的生成器，并对不支持输入返回 UnsetValue。 PropertyGeneratorConverter_SupportedProperty_ReturnsGeneratedControl 通过；项目构建成功。 补齐所有属性类型及单选/多选操作面板的参数化 headless UI 测试，重点断言双向写回、校验提示和撤销 action。
已修复
工具箱拖动物件到编辑器里面无法工作，物件并没有实际添加到编辑器上		 拖放源发送的是 ToolboxItemViewModel，编辑器只识别 ToolboxItem；同时没有处理 DragOver 来设置允许效果。已兼容两种 payload，补上 DragOver，统一清理拖放 token，并在创建对象为空时安全返回。 编辑器构建通过；拖放入口现在覆盖 DragEnter/DragOver/Drop，设计模式、锁定状态和无效对象均有明确分支。 增加真实指针拖放集成测试：验证 Move 效果、对象集合数量、坐标换算、一次撤销和 Drop 失败后的 token 清理。
已修复
部分DataGrid的宽度小于内容所需宽度，检查一下原因		 Avalonia DataGrid 的可调整列在空间不足时会压缩到默认最小值；迁移列没有设置内容级 MinWidth，且未开启横向滚动。已为六个受影响视图补充合理的列最小宽度和 HorizontalScrollBarVisibility="Auto"。 MigratedDataGrids_PreserveColumnMinimumWidthsAndHorizontalScrolling 覆盖六个视图，在 320px 宿主宽度下验证所有列不低于最小宽度。 新列同时审查 Width、MinWidth 和排序/重排行为；对窄窗口、长本地化文本和高 DPI 做快照或 headless 布局回归。
已修复
菜单点击时间计算器和当前选择物件查看器没出现对应界面，且对应菜单按钮变灰了		 两个命令处理器复制了元信息浏览器的接口解析，实际应解析各自的 ITGridCalculatorToolViewer 与 IFumenEditorSelectingObjectViewer，导致服务解析失败并使 CanExecute 变灰。已更正接口映射。 对应命令处理器已改为正确接口；全量 301 项测试通过，构建无错误。 为每个菜单命令建立“命令定义 - handler - tool interface”映射测试，并覆盖工具已打开时聚焦、未注册时禁用和切换文档后的 CanExecute。
已修复
编辑器Hold渲染出问题了，Hold长条被渲染成黑色而不是对应的颜色		 旧设置中的 System.Drawing.Color 被按对象形状反序列化为 Color.Empty（A/R/G/B 全为 0），渲染转换后自然变黑/透明。已加入兼容 JSON converter，按 ARGB 数字持久化，并在反序列化后对空颜色恢复默认 Hold 调色板。 EditorGlobalSettingJson_RoundTripsHoldColorsAsArgbNumbers、legacy object recovery 测试通过；完整测试 301/301。 为设置文件增加 schema/version 迁移；加入渲染像素或颜色转换回归，覆盖旧文件、透明色、自定义色和未知字段，避免设置格式再次漂移。
已修复
