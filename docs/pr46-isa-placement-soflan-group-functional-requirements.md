## 摘要

PR #46 的核心需求有两组：

1. **ISA 两点放置**：在画布上点选两个对角点创建 ISA，并归属到当前选中的变速组。
2. **变速组编辑**：组可以被创建、删除、在属性浏览器中重新归属，能够持久化，并在编辑模式下用组色区分。

所有会改变谱面数据的操作都应可撤销/重做；取消操作不得留下半成品。

### 需求来源与口径

- **PR 描述明确写出的要求**：ISA 两点创建、切换工具/文档/失焦取消未完成操作、组属性沿用属性浏览器共有属性规则、混合组值可统一赋值并撤销、新建/删除组可撤销、空组通过 SGWI 保存/重载、删除有引用组时提供替代组/连同引用删除/取消、非默认组 15% 染色且保留 alpha、默认组与预览不染色，以及 SFL/Avalonia/Unity/安装程序等范围边界。
- **根据 PR 行为补全的口径**：默认组不可删除、空组名回退为数字编号、一次激活只创建一个 ISA、组编号在撤销历史存在期间不被新组复用。这些行为在 PR 描述中没有逐字展开，本文按实际交互整理为需求口径。

## A. ISA 两点放置

| 编号 | 功能需求 | 用户可见行为 |
| --- | --- | --- |
| **A-1** | 进入条件 | ISA 放置只能在设计模式，批量模式下不可用；必须在变速组列表中选中一个有效组, 如果没选择则默认变速组0 |
| **A-2** | 激活方式 | 变速分组查看器添加一个checkbox用于指示和表示当前是否进入ISA命令放置模式，如果当前激活ISA命令放置模式则界面右下角出现类似于批量模式的界面面板，用于提醒用户当前已经是ISA命令放置模式且显示当前放置模式新建的是哪个变速组的 |
| **A-3** | 两点创建 | 激活后第一次点击确定矩形的一个角点，第二次点击确定对角点；第二次点击完成创建。 |
| **A-4** | 坐标吸附 | 两个角点分别沿用普通物件的吸附规则，不使用独立的坐标规则。 |
| **A-5** | 边界规范化 | 第二点早于第一点时，自动交换/规范化时间与水平边界，保证 ISA 的起止顺序正确。 |
| **A-6** | 越界保护 | 点击超出谱面时长的位置时给出提示，不创建 ISA。 |
| **A-7** | 目标组锁定 | 激活时确定目标组，并在本次放置期间保持不变，避免中途切换组导致归属不确定。 |
| **A-8** | 目标组失效 | 若目标组在放置过程中被删除或失效，取消放置并提示用户。 |
| **A-9** | 一次一个 | 一次激活只创建一个 ISA；完成或取消后退出放置模式，需要再次激活才能创建下一个。 |
| **A-10** | 完成反馈 | 创建完成后自动选中新 ISA，刷新属性浏览器，并显示其组归属。 |
| **A-11** | 撤销/重做 | ISA 创建进入撤销栈，撤销时移除对象，重做时恢复对象。 |

### A 组补充规则

1. 放置期间鼠标左键用于取点，不应同时触发普通物件放置、选择或拖拽。
2. 第一点和第二点都按当前画布的吸附设置计算，不另建一套网格。
3. 工具状态提示应能区分“等待第一点”和“等待第二点”。
4. 创建完成后不保留第一点；下一次激活必须从新的第一点开始。

## B. 中断与取消

| 编号 | 功能需求 | 用户可见行为 |
| --- | --- | --- |
| **B-1** | 再次点击工具取消 | 已激活时再次点击 ISA 放置按钮，退出放置模式。 |
| **B-2** | 切换工具取消 | 切换到其他编辑工具时，结束未完成的 ISA 放置。 |
| **B-3** | 切换文档取消 | 切换到其他谱面/文档后，不继续保留上一张谱面的放置状态。 |
| **B-4** | 失焦取消 | 编辑器窗口失去焦点时，取消未完成的两点操作。 |
| **B-5** | 右键/Esc 取消 | 放置期间右键或 Esc/取消选择应退出放置，不创建对象。 |
| **B-6** | 模式切换取消 | 进入批量模式或发生编辑模式切换时，取消放置。 |
| **B-7** | 其他工具接管取消 | 从工具箱拖放其他物件、快速创建其他物件等操作开始前，结束当前 ISA 放置。 |
| **B-8** | 取消结果 | 取消后不生成 ISA、不保留第一点、不写入撤销栈，也不留下跟随鼠标的旧预览或提示。 |

B 组的目标是保证“正在放置”和“已经退出放置”的状态始终一致，不能出现半个矩形或幽灵起点。

## C. 变速组属性编辑

| 编号 | 功能需求 | 用户可见行为 |
| --- | --- | --- |
| **C-1** | 属性展示 | Soflan、Keyframe Soflan、ISA 及其结束端点应在属性浏览器中显示所属变速组。 |
| **C-2** | 组选项 | 组属性使用下拉选择，只列出当前有效的组；打开下拉时刷新组列表。 |
| **C-3** | 单选编辑 | 选中单个对象时，下拉显示其当前组，选择其他组后立即修改归属。 |
| **C-4** | 多选编辑 | 多选时遵循属性浏览器“只显示所有选中对象共有属性”的规则；不同组造成混合值时，下拉显示未确定状态。 |
| **C-5** | 统一赋值 | 对混合值选择新组后，所有选中的共有属性对象统一归属到该组。 |
| **C-6** | 只读保护 | 只读属性不可通过下拉修改；选择已不存在的组应被忽略。 |
| **C-7** | 即时生效 | 组属性修改后，对象的组归属、组色和相关缓存立即更新。 |
| **C-8** | 可撤销 | 组属性修改进入撤销栈，支持撤销/重做。 |

### C 组补充规则

1. 组下拉显示组名，而不是只显示内部编号。
2. 多选对象类型不同时，不应显示仅部分对象拥有的组属性。
3. 组属性修改不应改变对象的其他属性或几何数据。

## D. 新建变速组

| 编号 | 功能需求 | 用户可见行为 |
| --- | --- | --- |
| **D-1** | 命名创建 | 在变速组列表输入组名并点击“新建组”。组名可为空；为空时使用数字编号作为显示名。 |
| **D-2** | 空组 | 允许创建不包含任何 Soflan/ISA 的空组。 |
| **D-3** | 立即出现 | 新组立即出现在组列表和属性浏览器的组下拉框中，并自动成为当前选中组。 |
| **D-4** | 撤销/重做 | 新建组可撤销/重做；撤销后组及其在列表中的位置消失，重做后恢复。 |

空组不是临时状态，必须参与保存和加载。

## E. 删除变速组

| 编号 | 功能需求 | 用户可见行为 |
| --- | --- | --- |
| **E-1** | 默认组保护 | 默认组不可删除；尝试删除时给出明确提示。 |
| **E-2** | 无引用组 | 没有任何 Soflan/ISA 引用的组可以直接删除，删除可撤销/重做。 |
| **E-3** | 有引用组 | 删除前必须弹出确认对话框，显示引用数量，并提供三种选择：转移到另一个有效组、连同所有引用对象删除、取消。 |
| **E-4** | 取消不修改 | 在确认对话框选择取消时，不得删除组、修改引用或写入撤销栈。 |
| **E-5** | 原子生效 | 选择转移或连同引用删除后，操作应作为一个整体生效。 |
| **E-6** | 撤销恢复 | 撤销删除时恢复组本身、组在列表中的位置、所有引用对象的原组归属，以及对象的选中/显示状态。 |
| **E-7** | 恢复被删对象 | 若删除时选择了“连同引用对象删除”，撤销时这些对象也必须恢复。 |

E-3 中的“引用对象”至少包括归属该组的 Soflan 和 ISA；删除/转移不能只处理其中一类。

## F. 持久化

| 编号 | 功能需求 | 用户可见行为 |
| --- | --- | --- |
| **F-1** | 保存内容 | 组定义、组名、组编号、空组以及 Soflan/ISA 的组归属应随谱面保存。 |
| **F-2** | 加载恢复 | 重新打开谱面后，组列表、空组、组名和对象归属应恢复。 |
| **F-3** | 旧谱面兼容 | 没有组数据的旧谱面加载时使用默认组，不能加载失败。 |
| **F-4** | 编号稳定 | 组编号在保存/加载、删除/撤销过程中保持稳定；已删除但可能被撤销恢复的编号不得被新组复用。 |
| **F-5** | 沿用 SGWI | 组信息沿用现有 `[SGWI]` 数据结构保存，不新增谱面文件格式。 |
| **F-6** | 不改变原生导出 | 不要求改变游戏原生 SFL 导出；组信息只服务于编辑器和 SGWI 持久化。 |

> 当前分支的方案 E 已把组树布局迁移到项目文件，这是后续实现变化，不是 PR #46 的需求。本文只描述 PR #46 的 SGWI 口径。

## G. 组色可视化

| 编号 | 功能需求 | 用户可见行为 |
| --- | --- | --- |
| **G-1** | 生效模式 | 仅在设计/编辑模式染色；预览模式不染色。 |
| **G-2** | 生效对象 | 仅对非默认组的物件染色；默认组不染色。 |
| **G-3** | 混色比例 | 在物件原色上混入 **15%** 组色。 |
| **G-4** | 保留属性 | 保留原透明度，不改变几何形状和命中范围。 |
| **G-5** | 可读性 | 选中高亮和文字标签保留原色，不被组色污染。 |
| **G-6** | 批次隔离 | 不同组的绘制批次不得串色。 |
| **G-7** | 不修改源数据 | 染色只影响显示，不得修改源绘制缓存或谱面对象颜色；关闭染色/切换组后应恢复原色。 |

组色是辅助识别手段，不应让用户误以为对象本身的颜色属性被修改。

## U. 撤销与状态一致性

| 编号 | 功能需求 | 用户可见行为 |
| --- | --- | --- |
| **U-1** | 可撤销操作 | ISA 创建、组属性修改、新建组、删除组、引用转移/删除都应进入撤销栈。 |
| **U-2** | 取消无副作用 | 取消放置、取消删除对话框、取消无效操作不改变谱面，也不产生撤销项。 |
| **U-3** | 状态恢复 | 撤销后对象的组归属、选中状态、组显示状态和组在列表中的位置应与操作前一致。 |
| **U-4** | 不产生半成品 | 任意中断路径都不能留下未完成的 ISA、未注册的组或只迁移了一半的引用。 |
