# PR #45 功能需求：子弹管理器持续放置与伤害快捷键

整理日期：2026-10-20；实现记录更新：2026-10-21。

本文件基于 [PR #45「子弹管理器持续放置与伤害快捷键」](https://github.com/NyagekiFumenProject/OngekiFumenEditor/pull/45)，并核对其来源 [PR #42](https://github.com/NyagekiFumenProject/OngekiFumenEditor/pull/42)。原始 PR 作者：[as2er](https://github.com/as2er)。整理时两者都没有额外的评论或审阅讨论。

**核心需求只有两组：选定模板后连续放置 Bullet／Bell，以及快捷调整已选中 Bullet 的伤害类型。** 本文件保留功能与交互要求。2026-10-20 用户明确：`FumenBulletPalleteListViewerView.xaml` 的界面外观与布局按 U 节指定的 PR #45 diff 对齐；随后移除 U-3 的原事件契约约束，新增复选框交互按 MVVM 实现，不照搬原 PR 的控件事件与状态管理方式。

## A. Bullet／Bell 连续放置

| 编号 | 功能需求 | 用户可见行为 |
| --- | --- | --- |
| **A-1** | 选择放置内容 | 用户能够选择一个模板，并指定接下来放置 **Bullet 或 Bell**。 |
| **A-2** | 放置选择全局互斥 | 同一窗口同时只能有一个活动的“模板＋物件类型”组合。选择另一个组合时，替换先前选择，不能同时激活多个。 |
| **A-3** | 鼠标携带预览 | 激活放置后，鼠标携带待放置物件的预览，提示当前准备放置的内容。 |
| **A-4** | 支持点击与拖放 | 用户可以通过点击或拖放完成放置。 |
| **A-5** | 可以持续放置 | 完成一次放置后仍保留当前选择，不必每放一个物件就重新选择模板。 |
| **A-6** | 遵循现有吸附设置 | 放置位置沿用用户当前的吸附设置，不使用另一套独立规则。 |

这里的重点是“**选一次，连续放多个**”。但原文的“拖放”不能直接解释成“按住鼠标沿途连续刷出物件”，后者没有明确提出。

## B. 放置状态的取消与保护

| 编号 | 功能需求 | 用户可见行为 |
| --- | --- | --- |
| **B-1** | 右键取消 | 处于放置状态时，右键退出放置；用于取消的这次右键操作不应同时弹出上下文菜单，包括释放鼠标时。 |
| **B-2** | 失焦时取消 | 活动编辑器切换到其他实例后清除放置状态；同一编辑器重复激活不取消。实现采用 `IEditorDocumentManager.OnActivateEditorChanged`。 |
| **B-3** | 切换谱面时取消 | 切换到另一张谱面后，不继续携带之前的放置状态。 |
| **B-4** | 切换模式时取消 | 编辑器模式发生切换时，清除放置状态。 |
| **B-5** | 其他工具接管操作时取消 | 开始其他工具的拖放操作时，结束当前 Bullet／Bell 放置。 |
| **B-6** | 当前模板失效时取消 | 当前使用的模板被删除时，不能继续放置。原 PR #42 将这一条件概括为“模板失效”。 |
| **B-7** | 不因重复指向同一谱面而误取消 | 当前谱面没有实际切换时，不应把重复指定同一个当前编辑器误判为切换，从而重置放置状态。 |

这些取消条件应当让“仍在放置”和“已经退出放置”保持一致，不能留下继续跟随鼠标的旧预览。

2026-10-21 实现口径：**B-1 由绘图区原有的 `PreviewMouseDown/PreviewMouseUp` 路径判断并取消放置，不再额外订阅窗口 `ContextMenuOpening`；B-5 由编辑器原有的 `Grid_Drop` 取消，不再订阅 `QueryContinueDrag`。** 因此右键取消只覆盖绘图区内的右键，其他面板上的右键不会取消；其他工具的拖放只在 Drop 实际落入编辑器时取消，不在拖放启动阶段取消。菜单抑制不在这两个原有事件的职责内。

## C. Bullet 伤害类型快捷调整

| 编号 | 功能需求 | 用户可见行为 |
| --- | --- | --- |
| **C-1** | 上下方向键切换伤害 | 选中 Bullet 后，通过 **↑／↓** 在 **普通、增强、危险** 三种伤害类型之间循环切换。 |
| **C-2** | 支持批量调整 | 对多个已选中的 Bullet 批量生效，而不是只能调整一个。此项在原 PR #42 中明确提出。 |
| **C-3** | Bell 不参与伤害切换 | 伤害调整只针对 Bullet，保留 Bell 原有行为；混合选择时也不应修改 Bell 的属性。此边界来自原 PR #42。 |
| **C-4** | 不干扰文本输入 | 焦点位于文本输入控件时，保留方向键原有的输入、导航行为，不触发 Bullet 伤害调整。 |

这里操作的是**谱面中已经选中的 Bullet**，应与 A 组“当前准备放置哪一种物件”的状态区分开。

## Q. 本轮采用的交互口径

以下项目原为 PR 文案未明确的边界。2026-10-21 按用户“按照文档实现”的要求，采用实施方案 D-1～D-4 的推荐口径；这是本轮实现选择，不追溯为原 PR 已明确的需求。

| 编号 | 交互项 | 实现口径 |
| --- | --- | --- |
| **Q-1** | 持续放置中的拖放语义 | 复选框开启持续放置；在编辑区单击或按下后拖动、释放，各创建一个物件，移动途中不创建。右侧旧链接保持单次拖放，开始时取消持续会话，结束后不自动重启。 |
| **Q-2** | “失焦”的范围 | 采用活动编辑器切换作为取消边界：`IEditorDocumentManager.OnActivateEditorChanged` 发现当前活动编辑器不再是本实例时取消；同一编辑器重复激活保持放置。不再使用顶层窗口失活事件。 |
| **Q-3** | 伤害循环规则 | ↑：`Normal → Hard → Danger → Normal`；↓反向。多个 Bullet 分别从各自原值循环，一次按键作为一个可撤销的批量动作；Bell 不变。 |
| **Q-4** | 快捷键配置 | 默认 ↑／↓，接入现有快捷键设置与保存／加载链路；改键后仍进行活动谱面、编辑模式和文本输入保护。 |
