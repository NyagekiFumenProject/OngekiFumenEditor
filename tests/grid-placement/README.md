# 独立无窗口回归

先构建该功能对应的 WPF 编辑器，再运行 `dotnet run --project tests/grid-placement/GridPlacement.csproj -p:EditorAssemblyDirectory=<构建输出目录>`。不创建编辑器窗口，不加入解决方案。

回归覆盖 Grid 规范化、复制粘贴几何、多选吸附、附轨更新、拖动回滚及真实撤销栈。

- Tap 与 Hold 头尾始终横向贴所属轨，时间依原开关吸附；局部选中物件各自依 X/T 设置吸附。整根轨道按实际起点吸附后，以统一 dx/dt 移动所有节点及控制点，保持形状与长度。
- 轨道变形后，未选 Tap/Hold 保留原时间并重新横向附轨；不自动删除音符。原轨范围外的导入音符不参与边界限制，无法投影则回滚。
- 起点从 5 拖向 7 时，若未选 Tap 位于 6，则起点停在 6；移除该 Tap 后可到 7。末端限制对称。整线触碰边界时整体修正时间，保持长度。
- 先吸附再限制边界；无法投影时整次回滚前一帧并恢复 IsDirty，拒绝拖动不增加撤销记录。
- 粘贴前验证全部克隆的轨道解析及投影；任一失败则整事务拒绝并提示，不添加对象或撤销记录。成功粘贴的 Undo 恢复原选择。
- 同时间水平轨段保留范围内 X，范围外取最近端点；同时间 Bezier 使用实际路径采样的 X 范围。仅 X 更新不重算全谱滚动指标。
